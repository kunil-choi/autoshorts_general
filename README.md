# autoshorts 범용 (autoshorts_general)

어떤 영상이든 **유튜브 링크** 또는 **영상 원본 파일**을 넣으면, AI(Claude)가 유튜브 쇼츠로 올리기 좋은 구간을
찾아주고, 자막을 고쳐 확인 영상을 본 뒤 유튜브에 **비공개**로 올릴 수 있게 도와주는 도구입니다.
특정 방송·프로그램에 묶여 있지 않아 강의, 발표, 대담, 브이로그, 사내 영상 등 무엇이든 쓸 수 있습니다.

> `autoshorts`(방송 콘텐츠 전용 버전)와 기능은 같고, 입력과 선택 항목만 일반화한 버전입니다.

## 범용 버전의 특징

| 항목 | 내용 |
|---|---|
| 영상 입력 | **유튜브 링크** 또는 **영상 원본 파일**(내 PC의 mp4 등. 화질 손실 없음, 유튜브에 안 올린 영상도 가능) |
| 후보 선정 기준 | **🎣 훅 위주**(첫 5초 안에 시선을 끄는 구간) / **📌 핵심 정보 위주**(영상의 핵심 논지·데이터·결론) / **🔎 키워드**(내가 적은 키워드와 관련된 발언만) - 기준별로 체크하고 개수(1~5개)를 정함 |
| 쇼츠 길이 | 30초 / 45초 / 1분 / 2분 / 3분 이내 중 선택, 또는 **사용자 지정**(15~180초) |
| 방송·프로그램 설정 | 없음 (로고 이미지도 선택 사항) |

## 어떻게 동작하나

무거운 작업(다운로드·음성인식·렌더링)은 사용하는 사람의 PC에서 직접 실행됩니다(하이브리드 구조). 유튜브 링크는
클라우드 서버 IP가 봇으로 차단되는 문제를 피하기 위해서고, 렌더링도 로컬에서 하는 편이 낫기 때문입니다.
화면은 **자동 생성**(`/auto`) 하나입니다.

### ✂️ 편집 시작 (단계별 작업)

토큰을 쓴 결과물이 마음에 안 들어 버리는 낭비를 줄이려고, 사람이 확인하고 고친 뒤에만 렌더링·업로드합니다.

```
1. 후보 분석   - 자막 추출(유튜브 자막, 없거나 파일이면 whisper 음성인식) + Claude가 선택한 기준대로 후보 선정
2. 자막 편집   - 후보마다 왼쪽에 선정 구간의 원본 영상(유튜브 플레이어 또는 내 파일, 렌더링 없이 바로 재생),
                 오른쪽에 스크롤되는 구간 전체 자막. 재생 중인 줄이 강조되고, 줄의 시간을 누르면 그 줄부터 재생
                 · 자막 글자는 눌러서 바로 수정 (자막만 바뀜)
                 · ✕로 줄을 삭제하면 그 부분이 영상에서도 잘림 (재생할 때도 건너뜀)
                 · 흐린 줄(구간 밖)의 +를 누르면 그 줄까지 구간에 포함
                 · 썸네일 문구 / 제목 / 출연자 표기 / 날짜 표기도 같은 화면에서 수정
3. 확인 영상   - 후보별로 최종 렌더링(제목 배너·로고·자막 포함)을 만들어 '확인 영상' 탭에서 봄
4. 재수정      - 수정하면 "다시 만들기 필요"로 표시. 자막만 고친 경우 잘라둔 영상은 재사용
5. 업로드      - 최신 확인 영상만 올릴 수 있음. 비공개로 올리고 유튜브 스튜디오가 열림 (공개 전환은 스튜디오에서 직접)
```

작업 상태는 `work/edit_jobs/`에 저장되어 앱을 껐다 켜도 이어서 할 수 있습니다. 업로드까지 끝난 작업은 7일 뒤
(올려둔 원본 파일 복사본 포함) 자동으로 정리됩니다.

### ⚡ 완전 자동

편집 없이 선택한 기준대로 후보를 모두 만들어 **비공개**로 업로드합니다. 시작 버튼을 눌러야만 동작하며
아무것도 저절로 시작되지 않습니다.

## 프로젝트 구조

```
src/autoshorts/
  sources/            - MediaSource 추상화 (YouTubeSource / UploadedFileSource)
  transcript.py       - 자막/whisper 결과를 타임스탬프 있는 Segment로
  analyze.py          - Claude로 후보 구간 제안 (hook / substantive / keyword) + 자막 교정
  clipbuild.py        - 여러 구간을 하드컷으로 이어붙이기
  render.py           - 세로형(9:16) 쇼츠로 합성
  youtube_upload.py   - 유튜브 업로드 (YouTube Data API v3)
  editjob.py          - 단계별 작업의 저장 구조와 편집 로직 (work/edit_jobs/)
  library.py          - 업로드 기록 ('오늘 N개' 표시용)
  config.py           - 길이 프리셋/사용자 지정 길이, 기준별 기본 개수
webui/                - 로컬에서 띄우는 웹앱 (FastAPI): 자동 생성 화면 + 단계별 편집 화면
default_assets/       - (선택) 쇼츠에 넣을 로고 이미지를 놓는 곳 (default_assets/README.txt 참고)
installer/            - Windows 원클릭 실행파일(.exe) 빌드
```

## 준비하기

1. **Claude API 키**: `webui/.env.example`을 `.env`로 복사(저장소 루트)하고 `ANTHROPIC_API_KEY=` 뒤에 키를 넣습니다.
2. **(업로드를 쓸 때만) 유튜브 업로드 인증**: 구글 클라우드 콘솔에서 YouTube Data API v3를 켠 프로젝트의
   OAuth 클라이언트(`client_secret.json`)를 발급받아 `.env`와 같은 위치(저장소 루트, 배포본은 `.exe` 옆)에 둡니다.
   첫 업로드 때 브라우저가 한 번 뜨면 올릴 채널 계정으로 로그인/동의합니다. 이후 `youtube_token.json`으로 자동 재사용됩니다.
   인증 파일 없이도 후보 분석·자막 편집·확인 영상까지는 모두 쓸 수 있습니다.
3. **(선택) 쇼츠에 넣을 이미지**: 기본 로고는 없습니다. 첫 화면의 "쇼츠에 넣을 이미지"에서 좌측 상단 / 우측 상단 /
   중앙 하단 자리에 원하는 이미지를 등록하면 이후 만드는 쇼츠에 들어갑니다. 비워 두면 그 자리는 비어 있습니다.
4. **(선택) 재생목록**: `.env`의 `AUTOSHORTS_PLAYLIST_ID`에 내 채널 재생목록 id를 넣으면 업로드한 쇼츠가 그 재생목록에도 추가됩니다.

## 로컬 웹앱 실행

```bash
pip install -r requirements.txt
uvicorn webui.server:app --port 8787
# http://localhost:8787 접속
```

`ffmpeg`/`ffprobe`가 PC에 설치되어 있어야 합니다 (Windows 배포본은 자동 포함).

## 테스트

```bash
pip install -r requirements.txt pytest
pytest
```

유튜브 다운로드·Claude API 호출처럼 외부 네트워크가 필요한 부분은 유닛 테스트로 검증할 수 없어서, 가짜로 바꾼 서버 테스트와
정규식/자막 파싱/ffmpeg 필터 구성 같은 순수 로직만 테스트로 커버합니다. 영상 파일 입력의 원본 구간 재생은 실제 브라우저
(Playwright)로 확인했지만, 실제 유튜브 다운로드·음성인식·ffmpeg 렌더링·업로드 API는 처음 쓸 때 결과를 한 번 확인해 주세요.

## 다른 PC에 배포하기 (Windows 원클릭 설치파일 만들기)

Python/ffmpeg를 몰라도 쓸 수 있는 실행파일을 `installer/`에서 만들 수 있습니다. **Windows에서 한 번만** 실행하면 됩니다.

```bat
installer\build.bat
```

`dist/autoshorts/` 폴더 전체를 zip으로 압축해 다른 PC에서 풀고 `autoshorts.exe`를 더블클릭하면 됩니다
(처음 실행 시 만들어지는 `.env`에 `ANTHROPIC_API_KEY`만 채우면 끝). GitHub Actions(`.github/workflows/build-windows.yml`)로도 빌드할 수 있습니다.
